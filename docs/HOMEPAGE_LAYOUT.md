# Hub OS 首页板块布局方案

> 2026-04-20 | 产品设计文档
> 状态：讨论稿

---

## 一、设计理念

首页不再是"对话+看板"两块平铺，而是一个多板块的综合工作台。

参考 Notion 的温暖极简风格：大量留白、whisper级别的边框、warm neutral色调、卡片化的信息组织。不堆砌，但内容丰富——每个板块都有存在的意义。

布局逻辑：顶部是团队信息条，下方是可滚动的多板块区域，对话框浮动在底部。

## 三、板块详解

### A. 核心对话区（固定左半边 或 顶部卡片）

这是管家对话的入口，但不再占满整个页面。变成一个「卡片」。

```
┌─────────────────────────────────────────┐
│  🧑‍💼 阿拓 · 在线                        │
│                                         │
│  阿拓: 早上好。今天有3件事需要确认...     │
│  你: 先处理品牌方案                      │
│  阿拓: 好的，火花已在处理...             │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │ 给阿拓发消息... @提及  📎  ➤  │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

设计要点：
- 高度固定（约400px），超出滚动
- 可以展开为全屏对话模式
- 输入框支持 @提及
- 最新消息在底部

### B. 半人马指数卡片

独立板块，不再藏在右侧面板里。给用户一个一目了然的人机协作全景。

```
┌─────────────────────────────────────────┐
│  ◐ 半人马指数                            │
│                                         │
│     ████████████████░░░░░░░  68         │
│     AI ──────────────── 人              │
│                                         │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│  │任务  │ │内容  │ │决策  │ │沟通  │   │
│  │78%   │ │75%   │ │60%   │ │38%   │   │
│  │██░░  │ │██░░  │ │██░░  │ │██░░  │   │
│  └──────┘ └──────┘ └──────┘ └──────┘   │
│                                         │
│  7日趋势 ▁▂▃▃▅▆▆█  ↑14  深度融合        │
└─────────────────────────────────────────┘
```

设计要点：
- 半宽或全宽卡片
- 主进度条 + 4维度小卡片横排
- 底部趋势线 + 等级标签
- 配色根据等级变化（金色=深度融合）

### C. 任务看板

紧凑的任务状态总览。

```

│  📋 任务看板                     5项     │
│                                         │
│  ● 进行中 2   ● 待审批 1   ● 已完成 2   │

│  🎯 客户案例集       小可  ███░░░  40%  │

│                                         │

设计要点：
- 顶部有状态分布条
- 进行中任务带进度条
- 待审批任务有操作按钮
- 已完成折叠

### D. 团队动态

时间线形式，展示今天团队都在做什么。让用户有"团队在运转"的感觉。

```

## 四、板块排列方案

### 方案一：瀑布流双列（推荐）

左右两列不等宽，板块交错排列，像 Notion 的灵活布局。

```
┌─ TeamHeader ────────────────────────────────────┐
│ 合伙人 │ 火花 小可 书熙 税宝 绿安 │ 半人马指数68 │
└─────────────────────────────────────────────────┘

┌── 左列 (60%) ──────────┐  ┌── 右列 (40%) ──────────┐
│                        │  │                        │
│  A. 核心对话            │  │  B. 半人马指数          │
│  （管家对话卡片）        │  │  （指数+维度+趋势）     │
│  ~400px高              │  │                        │
│                        │  ├────────────────────────┤
│                        │  │                        │
│                        │  │  E. 效能洞察            │
│                        │  │  （4个指标卡片）         │
├────────────────────────┤  │                        │
│                        │  ├────────────────────────┤
│  C. 任务看板            │  │                        │
│  （进行中+待审批+完成）  │  │  D. 团队动态            │
│                        │  │  （时间线）              │
│                        │  │                        │
└────────────────────────┘  └────────────────────────┘
```

优点：
- 对话区最突出，占据左上角黄金位置
- 半人马指数在右上角，一眼可见
- 信息密度高但不拥挤
- 自然的视觉流：左上(对话) → 右上(指数) → 左下(任务) → 右下(动态)

### 方案二：全宽卡片流

所有板块全宽排列，垂直滚动。

```
┌─ TeamHeader ─────────────────────────────┐
│ ... │
└──────────────────────────────────────────┘

┌── 对话区 (全宽) ──────────────────────────┐
│                                          │
└──────────────────────────────────────────┘

┌── 效能洞察 (全宽, 4列) ──────────────────┐
│  23项    18h    87%    96%               │
└──────────────────────────────────────────┘

┌── 半人马指数 (全宽) ──────────────────────┐
│  68 ████████░░░░  + 4维度                │
└──────────────────────────────────────────┘

┌── 任务看板 (全宽) ────────────────────────┐
│  ...                                     │
└──────────────────────────────────────────┘
```

优点：简单清晰。缺点：滚动多，信息密度低。

## 五、视觉规范

### 卡片风格（Notion风）
- 背景：白色 (#ffffff)
- 边框：1px solid rgba(0,0,0,0.08) — whisper级
- 圆角：16px（大卡片）、12px（小卡片）
- 阴影：多层极淡阴影
  rgba(0,0,0,0.04) 0 4px 18px,
  rgba(0,0,0,0.02) 0 2px 8px,
  rgba(0,0,0,0.01) 0 0.5px 3px
- 悬停：阴影微增，0.2s过渡

### 间距
- 板块之间：20px
- 板块内padding：20-24px
- 标题与内容：12-16px

### 字体层级
- 板块标题：14px 600 near-black
- 数据大字：28-36px 700 渐变色
- 正文：13px 400 charcoal-warm
- 标注：11px 400 stone-gray
- 徽章：10px 600 圆角pill

### 配色
- 页面背景：#f7f5f2（暖白）
- 卡片背景：#ffffff
- 主色：terracotta（半人马品牌色）
- 辅助：amber(任务)、emerald(完成)、blue(沟通)
- 文字：near-black / charcoal-warm / stone-gray 三级

## 六、交互细节

1. 对话卡片右上角有「展开」按钮 → 点击后对话区占满全屏（全屏对话模式）
2. 半人马指数卡片可点击 → 展开看更详细的分析
3. 任务看板的审批按钮点击后 → 对话区自动插入系统消息
4. 团队动态可以点击具体事件 → 跳到对应的员工或任务
5. 效能数据hover → 显示tooltip，说明计算方式

---

## 七、总结

首页 = 团队指挥中心，不只是聊天窗口。

5个板块各有职责：
- 对话：核心交互入口
- 半人马指数：人机协作的全景量化
- 任务看板：工作进度一目了然
- 团队动态：团队在运转的实时感
- 效能洞察：数据证明AI团队的价值

推荐方案一（瀑布流双列），信息密度和视觉美感兼得。
