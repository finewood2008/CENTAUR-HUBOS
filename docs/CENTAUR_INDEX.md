## 一、什么是半人马指数

半人马指数是一个 0~100 的比例值，表示当前企业工作中"AI承担"与"人工承担"的占比关系。

核心理念：不是AI越高越好，而是找到适合企业的最优人机配比。

### 表达方式

```
半人马指数: 62

意思是：62% 的工作由AI数字员工完成，38% 由人工完成。
```

### 为什么叫"半人马"

半人马（Centaur）= 人的智慧 + 马的力量。最强的不是纯AI也不是纯人，是人机结合体。

## 二、指数怎么算

### 2.1 计算维度

从4个维度评估人和AI各自承担的工作量：

| 维度 | 权重 | AI端怎么算 | 人工端怎么算 |
|------|------|-----------|------------|
| 任务执行 | 40% | AI完成的任务数 | 人工手动完成的任务数 |
| 内容生产 | 25% | AI生成的文章/设计/方案数 | 人工撰写/设计的数量 |
| 决策处理 | 20% | AI自动处理的决策数(如自动回复) | 需要人工审批/判断的决策数 |
| 沟通协调 | 15% | AI处理的客户/渠道消息数 | 人工亲自沟通的次数 |

### 2.2 计算公式

```
每个维度的AI占比 = AI完成量 / (AI完成量 + 人工完成量) × 100

半人马指数 = Σ(各维度AI占比 × 维度权重)
```

### 2.3 举例

某企业一周的数据：

| 维度 | AI完成 | 人工完成 | AI占比 |
|------|--------|---------|--------|
| 任务执行 | 18项 | 5项 | 78% |
| 内容生产 | 6篇 | 2篇 | 75% |
| 决策处理 | 30次 | 20次 | 60% |
| 沟通协调 | 50条 | 80条 | 38% |

半人马指数 = 78%×0.4 + 75%×0.25 + 60%×0.2 + 38%×0.15
           = 31.2 + 18.75 + 12 + 5.7
           = 67.65 → 约 68

解读：这家企业68%的工作由AI完成，人机配比接近 7:3。

## 三、指数区间与解读

| 区间 | 名称 | 含义 | 颜色 |
|------|------|------|------|
| 0-20 | 手工时代 | 几乎全靠人力，AI还没用起来 | 灰色 |
| 21-40 | 初步协作 | AI开始分担部分工作，但人工为主 | 蓝色 |
| 41-60 | 半人马状态 | 人机各半，开始进入协作节奏 | 绿色 |
| 61-80 | 深度融合 | AI承担主要工作，人做决策和创意 | 金色/琥珀 |
| 81-100 | 全面自动 | 高度自动化，人只做最终把关 | 紫色 |

最佳目标区间：**60-80**（深度融合），这才是"半人马"的精髓——AI干重活，人做判断。

## 五、数据来源（MVP阶段）

MVP阶段全部mock，但数据结构要设计好，方便后续接真实数据。

### 数据采集点（未来接SDK后）

| 维度 | 数据来源 |
|------|---------|
| 任务执行 | 管家分配的任务完成记录 |
| 内容生产 | 各智能体的产出记录（文章、设计、方案等） |
| 决策处理 | 审批流中AI自动处理 vs 人工审批的比例 |
| 沟通协调 | 各渠道（企微/飞书/TG）AI回复 vs 人工回复的比例 |

### Mock 数据结构

```typescript
interface CentaurIndex {
  overall: number;          // 综合指数 0-100
  dimensions: {
    tasks: { ai: number; human: number };       // 任务执行
    content: { ai: number; human: number };     // 内容生产
    decisions: { ai: number; human: number };   // 决策处理
    communication: { ai: number; human: number }; // 沟通协调
  };
  trend: number[];          // 最近7天的指数
  level: 'manual' | 'initial' | 'centaur' | 'deep' | 'auto';
  levelLabel: string;       // "深度融合"
}
```

## 六、产品价值

1. **给用户一个量化感知**——你的AI团队到底帮了多少忙，一目了然
2. **引导用户深度使用**——指数低的维度就是可以让AI多干的地方
3. **给投资人看的核心指标**——"我们的客户平均半人马指数68"，说明产品粘性强
4. **差异化**——市面上没人这么做，这是半人马AI的品牌符号
